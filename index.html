Yoink privacy policy

Last updated 5 September 2026

Yoink is a browser extension for Firefox and Chromium-based browsers (including Brave). It runs entirely on your device. Yoink does not operate a server, does not create accounts, and does not send your browsing data to the developer.

What Yoink does

Yoink lists audio the current tab has already loaded and lets you save a copy when you choose. It detects direct audio files, HLS and DASH playlists, and audio buffered through MediaSource in the page. Yoink does not unwrap DRM (Widevine, FairPlay, or similar).

Only save audio you have the right to keep.

Data stored on your device

  • Detected URLs and filenames — stored in the browser’s storage.session API, scoped per tab. The list stays until the browser session ends, the tab closes, or you clear the list from the popup.
  • Request headers (Cookie, Authorization, Referer, Origin) — kept in memory only (not in chrome.storage or other persistent extension storage), scoped to the tab, for up to 8 minutes. Yoink uses them only to fetch playlists and files from the same sites the tab already loaded. They are not uploaded anywhere.
  • Buffered MediaSource chunks — held in the extension background context in memory while you use the tab, so you can download concatenated buffered audio you already played.

Permissions and how they are used

  • webRequest — observe-only. Yoink listens for audio-related responses to detect media URLs and to stash request headers. It does not block or modify network traffic.
  • downloads — saves a file to your computer when you click Download (or use the context menu).
  • storage — uses storage.session for the per-tab media list described above.
  • tabs — ties detections and downloads to the active tab and clears data when a tab closes.
  • contextMenus — adds “Yoink this audio” on audio, video, and link elements.
  • clipboardWrite — copies a media URL to the clipboard when you click Copy in the popup.
  • scripting — re-injects content scripts after an extension reload when needed.
  • Host permission <all_urls> — content scripts on pages you open scan <audio>, <video>, and <source> elements and hook MediaSource appendBuffer in the page to reconstruct buffered audio. Yoink only runs on sites you visit; it does not browse on its own.

What the developer does not do

  • Collect, sell, or transfer user data
  • Use analytics or tracking
  • Run remote code — all extension code ships in the package you install
